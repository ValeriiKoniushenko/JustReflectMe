Reflect classes and fields

JRM reflects explicitly marked classes and structs. It generates identity metadata, metadata for direct fields, field lookup, and serialization helpers.

Declare a reflected type

CLASS();
class Entity
{
    R_FRIEND(Entity);

public:
    FIELD(R::Required, R::Attr = Identity);
    int id = 0;
};

CLASS();
class Task : public Entity
{
    R_FRIEND(Task, Entity);

public:
    FIELD();
    std::string title = "Untitled";

    FIELD();
    Priority priority = Priority::Normal;
};

The important rules are:

  • place CLASS() immediately before the definition, not a forward declaration;

  • place R_FRIEND(Type) inside the class, using the unqualified class name;

  • list serializable reflected bases after the class name in R_FRIEND(Derived, Base1, Base2);

  • place FIELD() immediately before each field that belongs to the reflection surface;

  • include the generated companion after all declarations in the header.

Public, protected, and private fields can be reflected because the generated R<T> specialization is a friend. Methods and unmarked members are not part of class field metadata. Treat unusual data declarators such as bit-fields and marked static members as unsupported unless a focused generator test proves the exact form.

Inspect metadata

    std::cout << R<Task>::FullName() << '\n';
    for (const RClassField& field : R<Task>::GetFields())
    {
        std::cout << field.type << ' ' << field.name << '\n';
    }

GetFields() returns RClassField entries containing a textual type, field name, and zero or more marker attributes. GetFieldsMap() indexes equivalent metadata by field name. Metadata describes fields declared directly in the type; base fields are serialized through the base specialization but are not added to the derived type’s GetFields() result.

Access a field by name

    const bool found = R<Task>::GetField(restored, "title",
                                         [](void* address, const char* type)
                                         {
                                             if (std::string_view(type) == "std::string")
                                             {
                                                 *static_cast<std::string*>(address) = "Published";
                                             }
                                         });

GetField calls the callback synchronously with an untyped address and textual type, and returns false for an unknown name or empty callback. The caller is responsible for checking the type string before casting. Because the API exposes mutable addresses and currently casts away constness for a reflected const field, reserve it for controlled infrastructure such as editors or serializers.

Defaults, requirements, and attributes

A field initializer becomes the generated deserialization fallback unless R::NoDefaultValue is present. Without a usable initializer, JRM value-initializes the field type as the fallback.

R::Required makes a missing JSON key an error; R::NonRequired is the default. R::Attr = Identifier records the identifier as metadata without changing serialization behavior. Multiple attributes are preserved in declaration order.

See Marker macros and field options for the complete option table.
