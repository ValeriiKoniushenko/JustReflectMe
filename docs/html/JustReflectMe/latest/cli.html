Command-line interface

The jrm executable scans one project root per invocation.

Generate reflection code

build/bin/jrm /absolute/path/to/your/project

The positional path must name an existing directory. Prefer an absolute path in build integrations; the program does not itself expand a literal leading ~.

During a scan, JRM reports reflected files, a final count of visited/eligible/updated files, warning and error totals, and elapsed time. It returns zero only when processing completes without reflector errors.

Information options

build/bin/jrm --help
build/bin/jrm --version
build/bin/jrm --fallback-config
Long option Short option Effect

--help

-h

Print usage and available options.

--version

-v

Print the generated project version and repository information.

--fallback-config

-f

Print the default YAML configuration to standard output without scanning a project.

In the current implementation, the informational options return exit status 1 after printing their output. Do not interpret that status as a generation failure when invoking them from scripts.

Additional positional arguments are currently ignored; configuration belongs in .jrm/config.yaml.
