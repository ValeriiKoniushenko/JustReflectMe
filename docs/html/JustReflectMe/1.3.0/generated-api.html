Generated R<T> API

JRM emits an explicit R<T> specialization for every successfully reflected declaration. This page summarizes the generated, application-facing surface.

Common identity functions

Member Meaning

Name()

Unqualified type name.

FullName()

Type name including namespace scopes.

ParentScope()

Enclosing namespace path, or an empty string at file scope.

These values are compile-time string views in generated specializations.

Class and struct specialization

Member Behavior

GetFieldNumbers()

Returns the number of directly reflected fields.

GetFields()

Returns a vector of RClassField values in declaration order.

GetFieldsMap()

Returns the direct-field metadata keyed by field name.

GetFieldsArray()

Returns a reference to a cached std::array<RClassField, N> in declaration order. It is built once, so element addresses are stable.

ForEachField(object, visitor)

Calls visitor(const RClassField&, FieldType&) for each direct field in declaration order. Accepts T& or const T&; the reference keeps the constness of the object and of the field.

ForEachMember(visitor)

Calls visitor(const RClassField&, std::integral_constant<FieldType T::*, &T::field>, setter) for each direct field in declaration order. setter is RNoSetter, or a captureless void(T&, const FieldType&) generated from R::Meta(Setter = …​).

GetBaseNumbers()

Returns the number of bases listed in R_FRIEND.

ForEachBase(visitor)

Calls visitor(std::type_identity<Base>{}) for each base listed in R_FRIEND, in that order.

Serialize(object, stream, noSignals)

Writes reflected base data and direct fields into an existing stream.

Serialize(object, noSignals)

Creates and returns a stream; JSON is the default implementation.

Deserialize(stream, object, noSignals)

Updates an existing object using serialized fields and generated fallbacks.

GetField(object, name, callback)

Invokes a callback with the mutable address and textual type of a direct field; returns whether it found the name.

To construct a value and deserialize it in one operation, RInternal::Deserialize<RImpl, T>(stream, noSignals, constructor arguments…​) is available. Treat RInternal as a lower-level helper: the generated in-place overload is the clearest stable entry point for most code.

Enum-class specialization

Member Behavior

Size()

Number of reflected enumerators.

ToString(value)

Returns the exact declared name, or an empty view when unknown.

FromString(name)

Returns an optional constant using case-sensitive lookup.

ToArrayC() / ToArrayN()

Return constants or names in declaration order.

ToMapCN() / ToMapNC()

Return constant-to-name or name-to-constant lookup maps.

Serialize(value, stream) / Serialize(value)

Write an enum’s symbolic name into a stream.

Deserialize(stream, value) / Deserialize(stream)

Update or return an enum from its symbolic name.

The in-place enum overload leaves an initialized destination unchanged when the name is unknown. Use that overload or FromString() for untrusted input; the value-returning overload default-initializes its local enum before lookup and therefore assumes the serialized name is valid.

Runtime support types

RClassField contains type, name, and attributes. attributes holds attribs (R::Attr identifiers), the optional min, max, and step limits, flags (every R:: option of the marker as bits), and meta (R::Meta entries in declaration order). Strings are non-owning views into generated string literals, while attribs and meta are vectors. hasFlag(flag), hasMeta(key), and getMeta(key) answer the common queries.

RMetaEntry is one R::Meta entry: a key and a value, both string views; the value is empty for a bare key.

RNoSetter is the empty type that ForEachMember passes for a field without a declared setter.

RResourceStream<RImpl> exposes write, read, getData, and logs and owns one implementation object. RJsonResourceStream stores nlohmann::json and missing-field diagnostics.

RStatus currently has Ok and NotFound; missing reads append NotFound, while successful reads do not currently append an Ok entry.
