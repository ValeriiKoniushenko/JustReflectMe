Marker macros and field options

Marker macros are declared by JustReflectMe/Adapter.h. They intentionally have no runtime behavior; the generator recognizes their source spelling.

Type markers

Marker Place it Effect

CLASS()

Immediately before a class or struct definition.

Generates a class-style R<T> specialization.

ENUM_CLASS()

Immediately before an enum class definition.

Generates enum identity, conversion, collection, and serialization functions.

R_FRIEND(Type, Bases…​)

Inside a marked class or struct.

Grants generated code private access. Arguments after Type select reflected bases for serialization.

FIELD(Options…​)

Immediately before a non-static data member in a marked class or struct.

Adds the member to metadata, lookup, and serialization.

CLASS() and ENUM_CLASS() may be on the declaration’s line or the preceding line, but keeping them on a dedicated preceding line produces the most readable and reliably scanned code. Leave their parentheses empty: the current reflectors interpret no arguments for either marker. Specify reflected bases in R_FRIEND(Type, Bases…​), not in CLASS().

Field options

Use FIELD() for defaults, or pass a comma-separated list of the options below. JRM matches their exact R:: spellings in source; RPoint:: aliases and arbitrary C++ expressions are not supported option syntax.

Option Meaning

R::Default

Default missing-field policy; currently equivalent to R::NonRequired.

R::NonRequired

A missing serialized field uses its generated fallback and adds a NotFound log entry without throwing.

R::Required

A missing field uses its fallback, logs NotFound, and throws std::runtime_error.

R::NoDefaultValue

Prevents JRM from copying the field’s source initializer into generated deserialization code. The generated fallback is value initialization.

R::Attr = Identifier

Adds Identifier to the field’s metadata attributes. Repeat the option for multiple attributes.

R::Meta(Entries…​)

Adds free-form key / key = value entries for tools such as editors, without changing serialization. See Tool metadata.

Unknown FIELD expressions produce generator warnings and are skipped as options. Attribute values are identifiers, not arbitrary strings or C++ expressions. The reflected-enum field path currently does not preserve every missing-field option; see Missing fields.

Every option given to a field is also recorded as a bit in RClassField::Attributes::flags; test it with attributes.hasFlag(RPoint::Required).

Tool metadata

R::Meta(…​) attaches metadata that JRM stores but does not interpret:

CLASS();
class Lamp
{
    R_FRIEND(Lamp);

public:
    void setBrightness(float value) { brightness = std::clamp(value, 0.f, 1.f); }

    FIELD(R::Min = 0.0, R::Max = 1.0, R::Step = 0.05,
          R::Meta(DisplayName = "Brightness", Category = Lighting, Setter = setBrightness));
    float brightness = 0.5f;

    FIELD(R::Meta(ReadOnly, Tooltip = "Assigned by the scene"));
    int sceneId = 0;
};

Each comma-separated entry is a key, optionally followed by = and a value:

  • the key is a plain identifier;

  • the value is an identifier (Lighting, Gui::AssetRef), a number (3, -2.5), or a string literal ("Brightness");

  • a bare key (ReadOnly) has an empty value.

Entries are available in declaration order as RClassField::Attributes::meta, a vector of RMetaEntry { key, value }. Look one up with attributes.getMeta("DisplayName"), which returns std::nullopt for an absent key and an empty view for a bare key, or test presence with attributes.hasMeta("ReadOnly"). String values are stored without their quotes; identifiers and numbers are stored as written.

A field may carry several R::Meta(…​) groups; their entries are merged in order. A repeated key produces a warning, and its last value replaces the earlier one in place. A malformed entry is reported as an error and skipped; the remaining entries are still parsed.

The Setter key is reserved. Setter = memberFunction must name a member function of the class; ForEachMember then passes a generated setter that calls object.memberFunction(value) instead of RNoSetter (see Visit fields with their real types). The member function is checked by the compiler when the generated header is compiled.

Friend aliases

Projects that wrap R_FRIEND in their own macro can list the recognized spellings in rFriendAliases. The alias must expand to the required friendship in compiled C++; configuration only teaches the source scanner which spelling to locate.
