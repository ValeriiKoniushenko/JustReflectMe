Reflect classes and fields

JRM reflects explicitly marked classes and structs. It generates identity metadata, metadata for direct fields, field lookup, and serialization helpers.

Declare a reflected type

CLASS();
class Entity
{
    R_FRIEND(Entity);

public:
    FIELD(R::Required, R::Attr = Identity);
    int id = 0;
};

CLASS();
class Task : public Entity
{
    R_FRIEND(Task, Entity);

public:
    FIELD();
    std::string title = "Untitled";

    FIELD();
    Priority priority = Priority::Normal;
};

The important rules are:

  • place CLASS() immediately before the definition, not a forward declaration;

  • place R_FRIEND(Type) inside the class, using the unqualified class name;

  • list serializable reflected bases after the class name in R_FRIEND(Derived, Base1, Base2);

  • place FIELD() immediately before each field that belongs to the reflection surface;

  • include the generated companion after all declarations in the header.

Public, protected, and private fields can be reflected because the generated R<T> specialization is a friend. Methods and unmarked members are not part of class field metadata. Treat unusual data declarators such as bit-fields and marked static members as unsupported unless a focused generator test proves the exact form.

Inspect metadata

    std::cout << R<Task>::FullName() << '\n';
    for (const RClassField& field : R<Task>::GetFields())
    {
        std::cout << field.type << ' ' << field.name << '\n';
    }

GetFields() returns RClassField entries in declaration order, each with a textual type, field name, marker attributes, numeric limits, the marker’s flags, and R::Meta entries. GetFieldsArray() returns the same entries from a cached std::array, so their addresses stay valid for the whole program. GetFieldsMap() indexes equivalent metadata by field name; it is unordered, so prefer the other two when order matters. Metadata describes fields declared directly in the type; base fields are serialized through the base specialization but are not added to the derived type’s GetFields() result.

Visit fields with their real types

    R<Task>::ForEachField(restored,
                          [](const RClassField& field, const auto& value)
                          {
                              // `value` has the field's real type: std::string, then Priority.
                              using Value = std::remove_cvref_t<decltype(value)>;
                              if constexpr (std::is_same_v<Value, std::string>)
                              {
                                  std::cout << field.name << " = " << value << '\n';
                              }
                          });

ForEachField(object, visitor) calls the visitor once per field, in declaration order, with the field’s metadata and a reference of the field’s real type. The reference is const when the object or the field is const. Overload resolution or if constexpr replaces comparing type strings, so this is the preferred way for tools to read and write fields.

To work without an object, ForEachMember(visitor) passes each field’s member pointer as a compile-time constant (std::integral_constant<FieldType T::*, &T::field>) together with a setter slot:

    Lamp lamp;
    R<Lamp>::ForEachMember(
        [&](const RClassField& field, auto member, auto setter)
        {
            const auto label = field.attributes.getMeta("DisplayName").value_or(field.name);
            std::cout << label << " = " << (lamp.*decltype(member)::value) << '\n';

            if constexpr (!std::is_same_v<decltype(setter), RNoSetter>)
            {
                setter(lamp, 2.f); // Calls Lamp::setBrightness, which clamps the value to 1.
            }
        });

The setter slot is RNoSetter unless the field declares R::Meta(Setter = memberFunction); then it is a captureless callable void(T&, const FieldType&) that calls that member function, which also converts to a plain function pointer. See Tool metadata for the marker.

Walk reflected bases

    R<Task>::ForEachBase(
        [](auto base)
        {
            using Base = typename decltype(base)::type;
            std::cout << R<Task>::Name() << " derives from " << R<Base>::Name() << '\n';
        });

ForEachBase(visitor) passes std::type_identity<Base> for every base listed in R_FRIEND, in that order. Combined with ForEachField, it lets a tool visit the fields of a whole class hierarchy without knowing the hierarchy in advance.

Access a field by name

    const bool found = R<Task>::GetField(restored, "title",
                                         [](void* address, const char* type)
                                         {
                                             if (std::string_view(type) == "std::string")
                                             {
                                                 *static_cast<std::string*>(address) = "Published";
                                             }
                                         });

GetField calls the callback synchronously with an untyped address and textual type, and returns false for an unknown name or empty callback. Prefer the typed visitors above when the reflected type is known at compile time. The caller is responsible for checking the type string before casting. Because the API exposes mutable addresses and currently casts away constness for a reflected const field, reserve it for controlled infrastructure such as editors or serializers.

Defaults, requirements, and attributes

A field initializer becomes the generated deserialization fallback unless R::NoDefaultValue is present. Without a usable initializer, JRM value-initializes the field type as the fallback.

R::Required makes a missing JSON key an error; R::NonRequired is the default. R::Attr = Identifier records the identifier as metadata without changing serialization behavior. Multiple attributes are preserved in declaration order.
